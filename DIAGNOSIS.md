# ДИАГНОЗ: ПОЧЕМУ МОДЕЛЬ НЕ СТРОИТ ЗДАНИЯ

## ПРОБЛЕМА
При запуске обучения модель не строит здания. `n_bases` остаётся 1 (только City).

## ТЕСТИ

### Тест 1: `step(0)` (Farm)
```python
obs, info = env.reset(seed=42)
print('n_bases before:', env.cpp_env.n_bases())  # 1
r = env.step(0)
print('n_bases after:', env.cpp_env.n_bases())   # 1
print('reward:', r[1])                           # 5.87
```

**РЕЗУЛЬТАТ:** `n_bases` НЕ МЕНЯЕТСЯ (1 → 1), но награда возвращается (5.87).

### Тест 2: `step(1)` (Garden)
```python
obs, info = env.reset(seed=42)
r = env.step(1)
print('reward:', r[1])  # 5.87
```

**РЕЗУЛЬТАТ:** Награда возвращается (5.87).

### Тест 3: `debug_find_lot()`
```python
env.cpp_env.debug_find_lot(0, False)  # None (Farm)
env.cpp_env.debug_find_lot(1, False)  # (101, 100) (Garden)
env.cpp_env.debug_find_lot(2, False)  # None (WaterChannel)
```

**РЕЗУЛЬТАТ:** 
- Farm НЕ НАХОДИТ КЛЕТКУ
- Garden НАХОДИТ КЛЕТКУ (101, 100)
- WaterChannel НЕ НАХОДИТ КЛЕТКУ

## ГИПОТЕЗЫ

### Гипотеза 1: `step()` НЕ СТРОИТ ЗДАНИЯ
- **ОБЪЯСНЕНИЕ:** `step()` проверяет, есть ли клетка, и если нет — не строит.
- **ПОДТВЕРЖДЕНИЕ:** `n_bases` остаётся 1 после `step(0)`.

### Гипотеза 2: `step()` ВОЗВРАЩАЕТ НАГРАДУ ДАЖЕ ЕСЛИ НЕ СТРОИТ
- **ОБЪЯСНЕНИЕ:** Награда может быть за "попытку" построить, а не за успешную постройку.
- **ПОДТВЕРЖДЕНИЕ:** `reward` = 5.87, но `n_bases` = 1.

### Гипотеза 3: `find_lot()` НЕ РАБОТАЕТ
- **ОБЪЯСНЕНИЕ:** `find_lot()` не находит подходящую клетку.
- **ПОДТВЕРЖДЕНИЕ:** `debug_find_lot(0, False)` = None.

## РЕШЕНИЕ

### Вариант 1: Позволить строить где угодно
- **ОПИСАНИЕ:** Убрать проверку `need_earth` из `find_lot()`.
- **ПЛЮСЫ:** Модель сможет строить любые здания.
- **МИНУСЫ:** Нарушает логику игры.

### Вариант 2: Исправить `find_lot()`
- **ОПИСАНИЕ:** Найти bug в `find_lot()`, который мешает найти клетку.
- **ПЛЮСЫ:** Сохраняет логику игры.
- **МИНУСЫ:** Нужно найти bug.

### Вариант 3: Научить модель выбирать подходящие здания
- **ОПИСАНИЕ:** Модель должна научиться выбирать Garden (индекс 1), а не Farm (индекс 0).
- **ПЛЮСЫ:** Модель учится.
- **МИНУСЫ:** Модель может не научиться.
